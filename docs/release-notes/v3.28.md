Installer-only release. The firmware itself is unchanged from v3.27 except for the version number.

## Web installer

- **Fixed a real stall**: "Backup, then install" used to try to click the actual install button for you once the backup finished. That click happened too late for the browser to still count it as a real gesture, so the install dialog silently never opened -- no error, nothing logged, just nothing happening. It's now an explicit two-step flow: "Backup, then install" reads the save, downloads it, then greys out and says "Backup complete, now →", pointing at a second "Install update" button that starts the actual flash with a real click.
- "Install without backup" is still there as a smaller link, for anyone who wants to skip straight to flashing without connecting for a backup first.
- The "Backup, then install" and "Connect board" buttons are green now, matching the firmware's own UI, instead of black.
- The install dialog itself now says **"Install TamaPoke v3.28"** instead of a bare "Install TamaPoke" that gave no hint which build was about to be flashed.

Existing saves are unaffected by any of this.
